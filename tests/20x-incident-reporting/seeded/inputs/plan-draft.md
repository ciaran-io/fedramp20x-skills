# Incident response plan (test input, draft)

> TEST INPUT. Seeded faults for the 20x-incident-reporting tests, plan review mode.

1. The on-call engineer handles incidents.
2. FedRAMP requires an initial report within 1 hour of detection.
3. Incidents are rated Low, Medium or High. Unrated incidents are treated as Low until the security lead has time to rate them.
4. Updates are sent when there is news.
5. A final report is sent when the security lead decides.
