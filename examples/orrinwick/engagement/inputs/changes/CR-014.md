## What changes

Agencies asked for alerts in their team chat. Beacon will add a fifth notification channel: a message to an agency's team chat channel, sent through a chat messaging service run by another company (new third party, T6).

- The notification workers (P2) gain a new outbound connection to the chat messaging service over HTTPS.
- Messages follow the same payload policy as push, email, SMS and voice: an alert reference ID and fixed text only, no alert summary (PF3).
- Agency administrators can turn the channel on for their tenant in the web console and add a chat channel address to an escalation rule. Each address is stored with the tenant's routing policy (D2).
- No change to the database, object storage, the intake API or the authorization boundary of other resources.

## Why

Requested by two pilot agencies. Responders in operations centres watch team chat more closely than email.

## Testing

New unit tests for the channel and the payload linter. A pilot with one agency tenant before release to all tenants.
